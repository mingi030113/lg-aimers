# 캘리브레이션 분석 — 우리는 어디서 틀리고 있나

## 1. 제출 점수 2개로 알 수 있는 것 / 없는 것

$$\text{Score} = 10^5 \cdot \frac{2\,\mathrm{Cov}(p,y) - \mathrm{Var}(p) - (\bar p - r)^2}{r(1-r)}$$

| | 기본 78피처 | +Trackman 100피처 |
|---|---|---|
| 2024 폴드 판별력 (R) | 725.0 | 740.8 |
| 실제 LB | **815.87199** | **828.18592** |
| 차이 | +90.9 | +87.4 |

**알 수 있는 것**

- 폴드에서 잰 Trackman 개선폭 +15.8 이 LB 에서 +12.3 으로 나타났다 → **폴드 델타가 약 78% 전이**된다.
  전방검증이 개선 측정 도구로 신뢰할 만하다는 뜻.
- LB = (2025 판별력) − (레벨손실) 이고 레벨손실 ≥ 0 이므로 **2025 판별력 ≥ 828**.
  2024 폴드(741)보다 최소 87 높다. 최종 모델이 6시즌으로 학습해 투수 이력이 더 길고,
  2025 자체가 더 변별 가능한 해였을 가능성.

**알 수 없는 것 — 레벨오차 $e = \bar p - r$**

두 제출은 **같은 목표평균**(R 0.4787 / F 0.4483)을 겨냥했다.
shift 상수가 −0.0395 vs −0.0443 로 다른 건 원 모델 평균 차이를 보정한 것뿐이라
설계상 도달 평균이 거의 같다 ($e_A \approx e_B$).
따라서 **두 점수만으로는 레벨오차와 판별력 변화를 분리할 수 없다.**

## 2. LB 탐침으로 분리하는 법 (계산은 되지만 권하지 않음)

예측 전체에 **미리 정한 상수 $\delta$** 를 더해 한 번 더 제출하면:

$$\Delta \text{Score}(\delta) = -10^5 \cdot \frac{2\delta e + \delta^2}{r(1-r)}$$

$r(1-r)$ 는 $r \in [0.46, 0.50]$ 에서 0.2484~0.2500 로 거의 상수라 무시 가능한 불확실성이다.
$\delta = 0.01$ 로 잡으면 $\Delta\text{Score} \approx -(8019\,e + 40.1)$ 이고,
LB 가 소수점 10자리까지 나오므로 $e$ 가 사실상 **완전히 특정**된다.

**기대 이득**: 백테스트상 $|e|$ 의 전형값이 0.005~0.008 이므로 회수 가능액은 **10~30점**.

**비용**: 규정 6항 "평가 데이터 전체를 보고 만든 사후 보정값" 에 실질적으로 해당한다.
점수는 전체 test 라벨의 함수이므로, 그걸 역산해 상수를 박으면 상위 100팀 코드 검증에서
정당화하기 어렵다. Phase 3 진출이 목표라면 **10~30점과 실격 위험을 맞바꾸는 셈**이다.

→ **권장하지 않음.** 아래 3~4번의 합법적 경로부터 소진할 것.

## 3. 레벨 오차는 오프라인에서 얼마나 줄일 수 있나 (결론: 거의 못 줄인다)

R 시즌평균 연간 변화: −0.0226, −0.0141, −0.0091, −0.0006, −0.0134
→ 평균 −0.0120, **표준편차 0.0080**. 현재 `DRIFT = −0.011` 은 이 평균 근처다.

기대 레벨손실 = $10^5 \times 0.0080^2 / 0.2494 \approx$ **26점**. 이게 드리프트 사전값의 한계다.

### 왜 test 의 asof 피처로 더 못 줄이나

`asof_pitcher_prev5_game_success_rate` 의 시즌평균은 실제 시즌평균을 ±0.009 로 따라간다.
하지만 **행 단위**로 쓰면 $\text{prev5}_i = L + s_i + \varepsilon_i$ 이고
투수실력 sd 0.040, 추정잡음 sd 0.029 → 한 행에서 리그레벨 $L$ 을 추정하면 sd 0.049.
오프셋으로 그대로 더하면 +0.0024 Brier = **−960점**.

수축계수 $\lambda$ 로 완화해도, 최적 $\lambda = D^2/(D^2+\sigma^2) = 0.146$ 에서
잔차 sd 가 0.0111 로 무보정(0.0120) 대비 거의 개선이 없다. $\sigma \gg D$ 이기 때문.

행 간 평균을 내면 해결되지만 그건 평가데이터 집계 = 규정 위반.
**"리그가 내려간 것"과 "이 투수가 나쁜 것"은 한 행 안에서 구별 불가능하다.**

## 4. 그래서 실제로 손댈 수 있는 곳

레벨(전역 평균)은 26점 언저리에서 막혀 있다. 남은 건:

- **신뢰도 기울기** $\mathrm{Cov}(p,y)/\mathrm{Var}(p)$ 가 1에서 벗어나면 재척도로 회수 가능
- **부분집단별 편향** — 월/이닝/볼카운트/투수경험/예측분위별로 체계적으로 치우친 곳.
  Brier 손실이 $\sum_g (n_g/N)\,\text{bias}_g^2$ 로 더해지므로 국소 보정이 그대로 점수가 된다.
  전부 train 만으로 추정 가능 = 합법.

## 5. 감사 결과 — 캘리브레이션은 이미 잡혀 있다

제출과 동일한 절차(train≤Y−1 → DRIFT/D_AUTO 시프트 → Y 평가)를 폴드에 재현:

| | 실제평균 | 예측평균 | 오차 e | 총점 | 판별력 | 레벨손실 | 기울기 |
|---|---|---|---|---|---|---|---|
| 2024 전체 | .4861 | .4872 | **+.0011** | 733.9 | 734.4 | **−0.5** | 1.055 |
| 2024 R | .4897 | .4915 | +.0018 | 739.9 | 741.1 | −1.3 | 1.088 |
| 2024 F | .4593 | .4555 | −.0038 | 362.7 | 368.5 | −5.8 | 0.919 |
| 2023 R | .5031 | .4933 | −.0099 | 518.2 | 557.1 | −38.9 | 0.951 |

- **2024 폴드의 레벨손실은 −0.5점.** 레벨 정책이 사실상 완벽하게 작동했다.
- 2023의 −38.9 는 그 해 드리프트가 ~0 이었는데 −0.011 을 가정한 탓. 사전값의 불가피한 위험.
- 2023 F 의 −16,987 은 **폴드 인공물**이다. 2022년 F 레벨(구 레짐 .709)로 시프트를 잡아서 그렇다.
  실제 제출은 2024 F 레벨(신 레짐)을 쓰므로 해당 없음.
- 기울기: 2023R 0.951 / 2024R 1.088 → 평균 ≈ 1.02. **재척도할 근거 없음** (부호가 뒤집힘).

### 부분집단 편향 (2024 폴드, in-sample 회수 가능액)

볼카운트 18.2 / 투수손×타자손 15.0 / 예측10분위 11.4 / 월 7.6 / 이닝 3.6 / 투수경험 3.2 / 타자경험 3.1

**전부 작다.** 게다가 in-sample 이라 잡음이 섞여 있다 —
그룹 G개·표본 N개면 순수 잡음만으로 $10^5 G/N$ 점이 나온다
(볼카운트 12그룹 / 25만행 → 잡음 바닥 4.7점).

→ 실제 이전 가능한지는 `cal02_recal.py` 에서 out-of-sample 로 검증.

## 5-b. 부분집단 재보정 — out-of-sample 검증 결과

한 폴드에서 그룹별 로짓 보정을 배워 다른 폴드에 적용한 실제 Δ점수 (R게임, 전역레벨 고정):

| 축 | in-sample (2024) | **out-of-sample** |
|---|---|---|
| 볼카운트 12칸 | +22.2 | **+11.1** |
| 주자상태 | +8.3 | +3.1 |
| 투수손×타자손 | +9.0 | +0.9 |
| 이닝 | +4.7 | −3.5 |
| 투수경험 | +3.6 | −3.6 |
| **월** | +8.3 | **−48.7** |

- **월별 보정은 재앙**이다. 시즌 내 월별 패턴은 해마다 달라 전혀 이전되지 않는다.
- **전역 재척도도 이전되지 않는다**: 2023 최적 s=0.95 를 2024 에 적용하면 −7.0
  (2024 자신의 최적은 s=1.10). 부호가 뒤집히므로 손대지 말 것.

### 볼카운트 보정만 진짜다 — 최적 형태 탐색

12칸보다 **b−s (볼 − 스트라이크, 6그룹)** 가 낫고, 수축계수 λ 를 걸면 양방향 모두 플러스:
